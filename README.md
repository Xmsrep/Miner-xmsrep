# Miner-xmsrep — Samsung Galaxy A21s

Projet expérimental de minage CPU sur Samsung Galaxy A21s (Exynos 850 / ARM64).

> **Important :** un smartphone n'est pas rentable pour miner Bitcoin ou la plupart des cryptomonnaies. Ce dépôt sert d'abord à mesurer les performances et la consommation, sans promesse de gains.

## État du projet

- [x] Dépôt initialisé
- [ ] Vérifier le modèle exact, la RAM et la version Android
- [ ] Installer Termux depuis F-Droid ou GitHub officiel
- [ ] Mesurer température, fréquence CPU et batterie au repos
- [ ] Évaluer un mineur ARM64 open source et son pool
- [ ] Faire un test court sous surveillance
- [ ] Calculer le rendement net (récompenses moins électricité)

## Sécurité

- Ne communique jamais ta phrase de récupération ou ta clé privée.
- Utilise une adresse de réception publique dédiée.
- Ne désactive pas les protections thermiques Android.
- Ne fais pas tourner le téléphone sans surveillance.
- Arrête le test si le téléphone chauffe anormalement, gonfle ou devient instable.
- Aucun binaire de minage n'est téléchargé ou exécuté automatiquement par ce dépôt.

## Pré-requis

- Samsung Galaxy A21s (ARM64)
- Connexion Wi-Fi stable
- Termux officiel
- Batterie en bon état
